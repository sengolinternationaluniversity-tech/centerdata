Institute Management Web Prototype
================================
Open index.html in a modern browser.

Features:
- Excel-like institute table
- Add/edit/delete
- Search and state filter
- Excel import/export (.xlsx/.xls) using SheetJS CDN
- Template download
- Browser localStorage persistence

Important:
This is a prototype. Data is stored only in the browser on the device where it is used.
For a production multi-user Admin/Staff system, the next version should add a secure backend database,
user authentication, permissions, cloud hosting, backups, audit logs and server-side Excel processing.
